# Daily Wellbeing Check-in

A small browser-based project for reflecting on sleep, movement, leisure screen time, and perceived stress. It calculates a transparent habit snapshot locally in the browser.

## Run it

Open `index.html` in a browser, or deploy this folder as a static site. On Render, create a Static Site, use this repository, leave the build command blank, and set the publish directory to `.`.

## How the score works

The score is a simple hand-written heuristic based on the four sliders. It is not a trained, validated, diagnostic, or predictive mental-health model. Answers are processed in the browser and are not sent to a server.
